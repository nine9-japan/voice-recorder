# シンプル録音アプリ (ボイスレコーダー)

ブラウザ上で手軽に音声を録音・再生・保存できる、ビルド不要のシンプルな Web アプリです。録音完了後に固定の Google Drive フォルダへ自動アップロードする機能（ON/OFF 切り替え）も備えています。

## 主な機能

- **ワンクリック録音**: 「録音開始」/「録音停止」ボタンで直感的に録音
- **一時停止 / 再開**: 録音中のポーズ・レジュームに対応（対応ブラウザのみ）
- **リアルタイム波形表示**: Web Audio API によるマイク入力レベルのビジュアライザー
- **経過時間タイマー**: `MM:SS` 形式の正確な録音時間表示
- **ブラウザ内保存 (IndexedDB)**: 録音データをブラウザ内に保存し、ページ再読み込み後も一覧を維持
- **タイトル編集・再生・ダウンロード・削除**: 一覧上でタイトル変更、ブラウザ再生、音声ファイル（`.webm` / `.m4a` / `.ogg`）のダウンロードが可能
- **Google Drive 自動アップロード（ON/OFF 切替）**: 録音完了時に固定の Google Drive フォルダへ自動アップロード（録音一覧から手動アップロード・再試行も可能）
- **共有**: 各録音の「共有」ボタンから OS の共有シートで音声ファイルを共有（非対応ブラウザでは Drive 保存済みリンクのコピーに対応）

## ローカルでの起動方法

マイク機能 (`getUserMedia`) を利用するため、`file://` 直開きではなくローカル HTTP サーバー経由（`http://localhost`）で開いてください。

```bash
python3 -m http.server 8000
```

起動後、ブラウザで以下にアクセスします：

- http://localhost:8000

> **注意**: ブラウザのセキュリティ仕様により、マイクアクセスは `https://` または `http://localhost`（`127.0.0.1`）環境でのみ許可されます。

## Google Drive 自動アップロードの設定

共有先の Google Drive フォルダは以下に固定されています（[gas/Code.gs](gas/Code.gs) の `DEFAULT_FOLDER_ID` と一致）。

- https://drive.google.com/drive/folders/1dWUZTYz1n64cyUvk93t3hpqfjaNtuAh9

接続方式は **Google Apps Script (GAS) 経由** のみに簡素化されており、普段の操作は画面上の **ON / OFF スイッチだけ** で完結します。

### 1. GAS ウェブアプリをデプロイする（初回のみ）

1. [Google Apps Script](https://script.google.com/) で「新しいプロジェクト」を作成します。
2. 同梱の `gas/Code.gs` の内容をすべてコピーして `Code.gs` に貼り付けます。
3. 右上の「**デプロイ**」→「**新しいデプロイ**」をクリックします。
4. 種類の選択（歯車アイコン）で「**ウェブアプリ**」を選び、以下を設定します：
   - **次のユーザーとして実行**: `自分`
   - **アクセスできるユーザー**: `全員`
5. 「デプロイ」を押し、権限の承認画面が出たら Google Drive へのアクセスを許可します。
6. 発行された「**ウェブアプリ URL**」（`https://script.google.com/macros/s/.../exec`）をコピーします。

> **ヒント**: `Code.gs` を書き換えた場合は、単なる保存ではなく必ず「デプロイ」→「デプロイを管理」（または「新しいデプロイ」）から新バージョンとして再デプロイしてください。

### 2. URL を設定する（次のどちらか一方）

- **方法 1（ブラウザで 1 度だけ入力）**: アプリの「**URL設定**」ボタンを開き、発行された GAS ウェブアプリ URL を貼り付けて「**完了**」を押します。URL はブラウザ（`localStorage`）に保存され、以降は ON/OFF スイッチだけで使えます。
- **方法 2（入力欄を完全に消して ON/OFF のみにする）**: [drive.js](drive.js) 先頭の `FIXED_GAS_URL` に発行された GAS ウェブアプリ URL を直接書き込んで公開します。`FIXED_GAS_URL` が設定されている場合、画面上の「URL設定」ボタンと入力欄は自動的に非表示になり、すべての端末で完全に ON/OFF だけの操作になります。
