# シンプル録音アプリ (ボイスレコーダー)

ブラウザ上で手軽に音声を録音・再生・保存できる、ビルド不要のシンプルな Web アプリです。録音完了後に指定の Google Drive フォルダへ自動アップロードする機能（ON/OFF 切り替え可能）も備えています。

## 主な機能

- **ワンクリック録音**: 「録音開始」/「録音停止」ボタンで直感的に録音
- **一時停止 / 再開**: 録音中のポーズ・レジュームに対応（対応ブラウザのみ）
- **リアルタイム波形表示**: Web Audio API によるマイク入力レベルのビジュアライザー
- **経過時間タイマー**: `MM:SS` 形式の正確な録音時間表示
- **ブラウザ内保存 (IndexedDB)**: 録音データをブラウザ内に保存し、ページ再読み込み後も一覧を維持
- **タイトル編集・再生・ダウンロード・削除**: 一覧上でタイトル変更、ブラウザ再生、音声ファイル（`.webm` / `.m4a` / `.ogg`）のダウンロードが可能
- **Google Drive 自動アップロード（ON/OFF 切替）**: 録音完了時に指定の Google Drive フォルダへ自動アップロード（録音一覧から手動アップロード・再試行も可能）
- **共有**: 各録音の「共有」ボタンから OS の共有シートで音声ファイルを共有（非対応ブラウザでは Drive 保存済みリンクのコピーに対応）

## ローカルでの起動方法

マイク機能 (`getUserMedia`) を利用するため、`file://` 直開きではなくローカル HTTP サーバー経由（`http://localhost`）で開いてください。

```bash
cd /home/hatch/.gemini/antigravity-cli/scratch/voice-recorder
python3 -m http.server 8000
```

起動後、ブラウザで以下にアクセスします：

- http://localhost:8000

> **注意**: ブラウザのセキュリティ仕様により、マイクアクセスは `https://` または `http://localhost`（`127.0.0.1`）環境でのみ許可されます。

## Google Drive 自動アップロードの設定

アプリ画面上の「**Google Drive 自動アップロード**」スイッチでいつでも **ON / OFF** を切り替えられます。既定の保存先フォルダは以下に設定されています。

- https://drive.google.com/drive/folders/1dWUZTYz1n64cyUvk93t3hpqfjaNtuAh9

ブラウザから Google Drive へファイルをアップロードするため、以下の **2通りの接続方式** から選べます（おすすめは **方式 A: Google Apps Script 経由** です）。

### 方式 A: Google Apps Script (GAS) 経由（GCP 不要・おすすめ）

1. [Google Apps Script](https://script.google.com/) で「新しいプロジェクト」を作成します。
2. 同梱の `gas/Code.gs` の内容をすべてコピーして `Code.gs` に貼り付けます。
   - （任意）第三者からのアップロードを防ぎたい場合は、`SHARED_TOKEN` に任意の文字列を設定するか、スクリプト プロパティに `UPLOAD_TOKEN` を設定してください。
3. 右上の「**デプロイ**」→「**新しいデプロイ**」をクリックします。
4. 種類の選択（歯車アイコン）で「**ウェブアプリ**」を選び、以下を設定します：
   - **次のユーザーとして実行**: `自分`
   - **アクセスできるユーザー**: `全員`
5. 「デプロイ」を押し、権限の承認画面が出たら Google Drive へのアクセスを許可します。
6. 発行された「**ウェブアプリ URL**」（`https://script.google.com/macros/s/.../exec`）をコピーし、アプリの「設定」パネルにある「**GAS ウェブアプリ URL**」に貼り付けます（トークンを設定した場合は「共有トークン」にも同じ文字列を入力します）。
7. 「**Google Drive 自動アップロード**」のスイッチを **ON** にすると、以降の録音が完了したタイミングで自動的にフォルダへアップロードされます。

> **ヒント**: `Code.gs` を書き換えた場合は、単なる保存ではなく必ず「デプロイ」→「デプロイを管理」（または「新しいデプロイ」）から新バージョンとして再デプロイしてください。

### 方式 B: Google OAuth 2.0 直接接続（Drive API v3）

1. [Google Cloud Console](https://console.cloud.google.com/) でプロジェクトを作成または選択し、「**Google Drive API**」を有効にします。
2. 「OAuth 同意画面」を設定し（テスト中の場合は対象ユーザーに自身の Google アカウントを追加）、スコープとして `https://www.googleapis.com/auth/drive` を許可します。
3. 「認証情報」→「認証情報を作成」→「**OAuth クライアント ID**」（種類: ウェブ アプリケーション）を作成し、「**承認済みの JavaScript 生成元**」に利用するオリジン（例: `http://localhost:8000` や GitHub Pages の URL）を追加します。
4. アプリの「設定」パネルで接続方式を「**Google OAuth 2.0 直接接続**」に切り替え、発行された **クライアント ID** を入力して「**Google に接続**」を押します。
5. 自動アップロードスイッチを **ON** にすると、録音完了時にブラウザから直接 Drive API へアップロードされます。
